# 🧮 Professional Calculator

A modern and responsive calculator built using **HTML, CSS, and JavaScript**.  
This calculator supports both **button clicks and keyboard input**, providing a smooth and professional user experience.

---

## 🚀 Features

- ✅ Clean and modern UI (Dark theme)
- ✅ Fully responsive design
- ✅ Basic arithmetic operations (+, −, ×, ÷, %)
- ✅ Keyboard support (like real calculator)
- ✅ Error handling
- ✅ Backspace & Clear functionality

---

## ⌨️ Keyboard Controls

| Key            | Function            |
|----------------|--------------------|
| 0–9            | Numbers input      |
| + - * /        | Operators          |
| .              | Decimal point      |
| Enter          | Calculate result   |
| Backspace      | Delete last digit  |
| Escape (Esc)   | Clear display      |
